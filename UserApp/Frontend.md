# UserApp - Frontend

## Overview
This frontend serves end users and bulk buyers who want to browse produce, place orders, negotiate pricing, and track delivery.

## Core Features
- Product discovery and search
- Category and location browsing
- Product detail and pricing comparison
- Cart and checkout flow
- Bulk requirement entry for large orders
- Order tracking and delivery updates

## Suggested stack
- React Native + Expo
- TypeScript
- React Navigation / Expo Router
- React Query for server state
- Tailwind or StyleSheet for UI

## Responsibilities
- Show buyer marketplace experience
- Allow consumer and bulk buyer flows
- Support order placement and tracking
- Render all order status labels consistently
