# UserApp - Backend

## Overview
This backend handles user and buyer-related workflows, including marketplace browsing, order placement, negotiation, and tracking data.

## Core Features
- Buyer registration and session management
- Product catalog and search APIs
- Cart and order placement endpoints
- Negotiation and offer APIs
- Bulk requirement creation and matching
- Order tracking and delivery status APIs

## Suggested stack
- Node.js + Express or Fastify
- TypeScript
- Supabase/PostgreSQL
- JWT + role validation
- Zod validation

## Responsibilities
- Secure buyer access and ownership
- Manage order creation from accepted offers
- Provide search and listing data
- Sync order state across buyer and farmer views
