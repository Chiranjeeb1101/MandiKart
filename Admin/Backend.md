# Admin - Backend

## Overview
This backend supports admin operations including moderation, analytics, dispute resolution, and user management.

## Core Features
- Admin authentication and permissions
- User verification and suspension actions
- Order and dispute monitoring
- Platform analytics and dashboard data
- Audit logging for key actions

## Suggested stack
- Node.js + Express or Fastify
- TypeScript
- Supabase/PostgreSQL
- Role-based access control
- Zod and middleware validation

## Responsibilities
- Protect privileged endpoints
- Maintain accurate audit logs
- Manage dispute resolution flows
- Provide aggregated platform insights
