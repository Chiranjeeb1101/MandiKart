# Admin - Frontend

## Overview
This web frontend is used by administrators to manage users, platform KPIs, orders, disputes, and moderation tasks.

## Core Features
- Dashboard with key platform metrics
- Farmer and buyer management
- Verification, suspension, and moderation actions
- Order monitoring and dispute handling
- AI insight panels and analytics

## Suggested stack
- React + Vite + TypeScript
- Tailwind CSS
- React Router
- TanStack Query

## Responsibilities
- Provide operational visibility to admins
- Enforce role-restricted access
- Handle moderation and dispute resolution workflows
- Monitor platform health and critical exceptions
