# FarmerApp - Backend

## Overview
This backend serves the Farmer App with APIs for authentication, listing management, orders, pricing, and fulfillment data.

## Core Features
- Farmer login and profile APIs
- Product CRUD operations
- Order lifecycle updates
- Negotiation handling
- Inventory status calculations
- Notifications and alerts

## Suggested stack
- Node.js + Express or Fastify
- TypeScript
- Supabase/PostgreSQL
- JWT/Auth middleware
- Validation with Zod

## Responsibilities
- Enforce farmer ownership rules
- Validate product and order actions
- Publish status updates to related systems
- Secure access to farmer-specific data
