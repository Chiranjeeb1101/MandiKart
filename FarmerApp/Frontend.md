# FarmerApp - Frontend

## Overview
This frontend is for farmers to manage produce listings, inventory, pricing, orders, and communication with buyers.

## Core Features
- Farmer authentication and profile setup
- Add/edit produce listings
- Inventory and stock tracking
- Order management and status updates
- Negotiation with buyers
- Earnings and sales overview

## Suggested stack
- React Native + Expo
- TypeScript
- Navigation with Expo Router
- State management with React Query / Zustand
- UI with NativeWind or React Native StyleSheet

## Responsibilities
- Show farmer dashboard
- Manage listings and crop details
- Handle order lifecycle updates
- Provide pickup and delivery visibility
